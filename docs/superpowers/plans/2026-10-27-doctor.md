# Environment Doctor Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver FR-007/MZ-007 and consume MZ-005 backup freshness without mutating diagnosed state.

**Architecture:** Core orchestrates independent structured checks, with read-only SQLite inspection in the state adapter. CLI parses explicit settings, invokes asynchronous diagnostics and renders static text or JSON.

**Tech stack:** Node 24+, node:sqlite, child_process fixed argv, strict ESM TypeScript, node:test.

**Spec:** docs/superpowers/specs/2026-10-27-doctor-design.md.

## Global constraints

- Remain in M-01: no ingest, live provider writes, scheduler, host provisioning or config schema changes.
- Diagnostic state access must not create/migrate a database or append events.
- No raw command output, paths, rejected arguments, credential material or caught error details in reports.
- Bound subprocess time/output, disable prompting, never execute shell text.
- Unconfigured/unimplemented integrations stay unavailable; an authentication probe proves only host identity access.

## Review focus

- Missing/old/foreign/corrupt state must fail without initialization or migration.
- Shared freshness semantics must remain identical, including data age and latest pending/failure.
- Secret checks must dispose handles without reveal or serialization, including partial failure.
- CLI invalid options/getters/raw command exceptions must not leak source values.
- Timeout/absent tools and unavailable integration must produce nonzero actionable output.
