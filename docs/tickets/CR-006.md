# CR-006 — Default owner-facing GitHub commands to readable output

Default `mz github permissions`, `mz github status` and `mz project checkout` to
readable summaries and practical next steps. Preserve their existing successful
objects behind explicit `--json` for agents/steward/scripts. Do not infer format
from a TTY. Native gh passthrough and Git's credential protocol stay unchanged.
Other existing command formats are outside this narrow change.
