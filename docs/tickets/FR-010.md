## Verification and limitations

Implemented 2026-10-27 on `fr-010-context-compiler`. The context package consumes Core's company repository port and compiles explicit company/role/project/task sources plus declared relevant processes/policies/decisions, with a required authority/security baseline. Source selection performs no directory scan, model/provider call, raw inbox access, runtime write or authority change. Curated provider references remain references only.

Output is deterministic across captured source/root/EOL/key-order equivalents, with ordered normalized SHA256/byte manifests, embedded digests, selected work reference, text and text byte count. Whole text and JSON responses obey one bounded budget; source/reference caps fail rather than truncate. Strict normalized Core reads preserve default general-loader behavior while rejecting source aliases/multiple links and parsing CR-only declarations correctly. Keys/values receive control/credential guards; symbolic secret references remain unresolved. Context is intentionally private curated knowledge, not diagnostic logging or an execution grant.

Verification: initial compiler15/CLI12 tests failed before implementation, then passed. Further red regressions covered symlink/hardlink isolation, excessive graph references, CR-only front matter scope/reference loss and metadata-key guard bypass. Independent review reproduced the last two Important findings; fixes were confirmed by reviewer, with97 context/CLI/company tests passed and no new actionable findings. Final compiler suite20 and real CLI suite12 cover source graph/isolation, normalized known digest, deterministic roots/EOL/key order, missing/mismatched/escaping material, exact JSON budget, graph/ref limits, safe errors/getters, credential detection and symbolic refs. Clean install exercises installed context from another directory. Generic template CLI smoke compiled12 sources (3852 text bytes), with no actual company context.

Final `npm run check` passed371 tests, build, lint and format; typecheck, local links and diff check passed. Existing company schema/SQLite migrations unchanged; the initial ephemeral bundle v1 contract is documented. No actual private organization sources, real credentials, model/provider, worker invocation or production deployment were exercised. Normalized hashes do not assert raw bytes or an atomic Git commit; use pinned/unchanging source revisions. PR/CI/merged-main evidence follows before Done. See [context](../context.md).
