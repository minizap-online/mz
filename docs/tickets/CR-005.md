# CR-005 — Print an SSH forwarding command during remote App setup

## Outcome

The owner reaches a loopback App setup page on the devbox and needs an actual SSH forwarding command, rather than an instruction to work out forwarding. Print a copyable command with the active browser/local and devbox ports, say to run it on the browser's computer in a separate terminal, and keep init/tunnel open. Do not guess a public host or local SSH alias from the server address. An explicit MZ_SSH_DESTINATION may supply the normal user@host or alias; otherwise use a clearly explained replacement destination. Existing forwarded HTTPS origins retain their own access guidance.
